# Yea Doc — Prototype

Clickable prototype for **Yea Doc**, a web app that connects churches with vetted musicians.

It includes:
- **Marketing site:** the "For Churches" / "For Musicians" landing page, built 1:1 from the Figma design.
- **Web app:** search, profiles, ratings, gigs, messaging and the sign-up questionnaires, with sample data.

Use the switch at the top of the page to move between the website and the app.

This is a design prototype: all people, churches, gigs and reviews are sample data, and nothing you enter is saved.

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```
